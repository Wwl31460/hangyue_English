# 航悦英语 · 账号与登录 详细操作说明

> 适用：老师/管理员第一次把账号系统跑起来，以及日常添加学生、学生登录。
> 目标：学生用「用户名 + 密码」登录，进度自动存云端、换设备可恢复。

---

## 一、先搞懂原理（30 秒，很重要）

- 学生在 App 里登录只用 **用户名 + 密码**（用户名可以是中文，如 `小明`，也可以是英文，如 `xiaoming`）。
- 但 Supabase（后台数据库）底层要求每个账号必须有一个“邮箱”才能登录。
  **这个邮箱你不用填**——系统按用户名自动生成：
  - 英文用户名 `xiaoming` → 自动变成 `xiaoming@hangyue.local`
  - 中文用户名 `小明` → 系统自动生成一个编码后的合法邮箱（你看不到，也不用管）
- 所以**最省事、最不会出错的做法是：用 App 里的「老师后台」添加学生**，邮箱格式由系统保证正确。
- ❌ **不建议**去 Supabase 后台手动 “Add user” 建账号——一旦邮箱格式填错（比如填了真实邮箱、或中文名直接填 `小明@hangyue.local`），App 就登不进去。

---

## 二、老师第一次准备（只做一次）

### 第 1 步：建数据表（在 Supabase 后台跑一次 SQL）
1. 打开后台：`https://cqasnjbpglubtgwgkjvq.supabase.co`，用你的 Supabase 账号登录。
2. 左侧菜单点 **SQL Editor**（SQL 编辑器）。
3. 点 **New query**（新建查询），把本目录下的 `schema.sql` **全部内容**复制粘贴进去。
4. 点右上角 **Run**（或 ▶ 运行）。
5. 怎么算成功：下面结果区显示 `Success. No rows returned.` 或没有任何红色报错即可。
   - 这张表用来存每个学生的进度；建一次就够了，以后不用再动。

### 第 2 步：关闭“邮箱确认”（关键！否则学生登不进）
1. 左侧菜单 **Authentication** → **Providers**（有的版本叫 Email 设置）。
2. 找到 **Email** 这一项，点开。
3. 把 **Confirm email（确认邮件）** 的开关 **关掉**。
4. 保存。
   - 作用：学生在 App 里添加后，不用去点验证邮件就能直接登录。
   - 如果不关这开关，学生账号会是“未确认”状态，登录会提示 *Email not confirmed*，卡在这里。

> 说明：第 1、2 步是“一次性准备”。之后加学生、学生登录，都在 App 里完成，不用再来后台。

---

## 三、添加学生（以后每次加人都这么做）

1. 打开「航悦英语」App（桌面版 exe，或开发预览地址）。
2. 进入 **「我的」** 页（首页右下角「我的」）。
3. 页面最下方点 **老师后台（添加学生账号）**。
4. 输入 **老师口令**（默认 `wwl31460`，见文末“改口令”）→ 点「进入」。
5. 填写：
   - **用户名**：学生的名字，中文或英文都行。例如 `小明` 或 `xiaoming`。
     （这就是学生以后登录时输入的名字。）
   - **密码**：至少 6 位，例如 `123456`。
   - **确认密码**：再输一次同样的密码。
6. 点 **添加学生**。
7. 出现「已添加学生：小明」即成功。这个学生现在就能用 `小明` + 密码登录了。
8. 一个学生加一次即可；加错了可以忽略，或去 Supabase 后台 Users 里删掉重加。

---

## 四、学生登录

1. 打开 App → 首页右上角点 **登录**（或在「我的」页点 **登录同步**）。
2. 输入 **用户名** + **密码** → 点登录。
3. 登录成功后：
   - 进度自动保存到云端；
   - 首页会出现「**继续学习**」卡片，一点跳回上次学的单元；
   - 右上角小字显示同步状态（已同步 / 保存中 / 同步失败）。
4. 换一台电脑或重开 App，只要登录同一个用户名，进度自动恢复。

---

## 五、登录报错了？对照这张表

| 提示 | 原因 | 怎么办 |
|---|---|---|
| **邮箱未确认 / Email not confirmed** | 没关“Confirm email”，或这个账号没激活 | 去 Supabase **Authentication → Users**，点该用户，设为“已确认”；或按「二-第2步」关掉确认，然后删掉该学生、用 App 内「老师后台」重新加 |
| **用户名或密码不正确 / Invalid login credentials** | 多半是你在 Supabase 后台手动建用户时邮箱格式不对（填了真实邮箱，或中文名直接填了 `小明@hangyue.local`） | 在 Supabase **Users** 里删掉那个用户，改用 App 内「老师后台」添加（邮箱由系统保证正确） |
| **一直转圈 / 没反应** | 网络问题（Supabase 在国内偶尔慢） | 确认电脑能上网；等几秒重试 |
| **提示“同步失败”但能登录** | `schema.sql` 还没跑，进度表不存在 | 按「二-第1步」跑一次 `schema.sql`；不影响登录，只是进度暂存本机 |

## 六、如果你已经在 Supabase 后台建了一个用户、登不进（最常见情况）

最省事的办法：
1. 打开 Supabase 后台 → **Authentication → Users**。
2. 找到你手动建的那个用户，点右边「…」→ **Delete user（删除）**。
3. 回到 App，按「三、添加学生」用 **App 内「老师后台」** 重新添加。
   这样邮箱格式一定对，且只要关了“Confirm email”就能直接登录。

---

## 七、改老师口令（可选）

老师口令现在写死在代码里，默认 `wwl31460`。想换成只有你知道的口令：
- 打开 `src/pages/Teacher.tsx`，找到第一行：
  ```ts
  const TEACHER_PIN = 'wwl31460';
  ```
- 把 `'1234'` 改成你的口令（建议 4 位以上数字），保存后重新打包即可。
- 学生看不到这个入口的内容，进不去「老师后台」。

---

## 八、一句话总结

**后台只准备一次**（跑 `schema.sql` + 关掉 Confirm email）；**加学生全部在 App 的「老师后台」里点**；**学生用用户名+密码登录**。别去 Supabase 后台手动建用户，最容易格式对不上导致登不进。
